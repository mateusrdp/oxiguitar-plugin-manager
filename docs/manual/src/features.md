# Features and their tests

Everything the Plugin Manager does, and the tests that check it. The test names are the ones `cargo test` prints. `scripts/test-all.py` fails when a feature here names no test, or names a test that doesn't exist, so a new feature gets its row and its tests in the same pull request (the [Testing](testing.md) page says how to run them).

| Feature | What it does | Tests |
| --- | --- | --- |
| Every copy listed | Every plugin file OxiGuitar found, a line a copy, grouped by plugin, with its version, folder and whether it is used; a file whose manifest can't be read is listed by its name. | `dialog::tests::every_copy_is_listed_and_only_the_users_are_deleted`, `files::tests::every_copy_is_an_entry_and_the_newest_version_is_known` |
| System copies stay | A copy in a system folder is greyed out and can't be deleted; one inside the macOS app can't either; one beside a portable copy can when its folder can be written. | `files::tests::system_copies_are_never_deleted_and_the_macos_app_s_neither`, `files::tests::a_folder_that_can_be_written_is_told_apart`, `dialog::tests::every_copy_is_listed_and_only_the_users_are_deleted` |
| The network mark | A `!` after a plugin whose file imports the system's network functions; this plugin is marked. | `network::tests::network_calls_are_told_by_name_and_library`, `network::tests::what_isnt_a_library_says_so`, `contract::the_plugin_file_is_read_as_the_dialog_reads_others` |
| The newest release | A GitHub homepage names its repository; the newest release that isn't a draft and has a zip for this system is taken, pre-releases included; GitHub's hourly limit says when it lifts. | `releases::tests::a_github_homepage_names_its_repository`, `releases::tests::the_newest_release_with_a_file_for_this_system_is_taken`, `releases::tests::the_target_is_one_of_the_releases_names`, `releases::tests::the_hourly_limit_says_when_it_lifts` |
| Updating | Offered only when the newest release is newer than every copy; the download is checked against the release's SHA256SUMS, the plugin's files are taken from the zip and installed under the packages' names. | `dialog::tests::an_update_is_offered_only_when_a_release_is_newer`, `install::tests::a_download_is_checked_against_the_release_s_sums`, `install::tests::a_zip_without_the_plugin_says_so`, `install::tests::a_release_s_file_is_installed_under_the_package_s_name` |
| Installing a file | Only an OxiGuitar plugin file is copied into the user's folder, where OxiGuitar then finds it. | `install::tests::only_a_plugin_file_is_installed`, `contract::a_plugin_file_installed_in_the_user_s_folder_is_found_there` |
| Safe writes | A file replaces another whole, through a temporary name; what an interrupted write or a loaded copy on Windows left is cleaned up. | `install::tests::a_file_replaces_another_whole_and_leaves_nothing_behind` |
| A working plugin file | The `.oxp` file keeps the plugin contract, with this repository's SDK version and with the newest release of OxiGuitar. | `contract::the_plugin_file_keeps_the_contract`, `oxiguitar_plugin_checks::the_manifest_matches_the_plugin`, `stage:contract (latest core)` |
