# Features and their tests

Everything the Plugin Manager does, and the tests that check it. The test names are the ones `cargo test` prints. `scripts/test-all.py` fails when a feature here names no test, or names a test that doesn't exist, so a new feature gets its row and its tests in the same pull request (the [Testing](testing.md) page says how to run them).

| Feature | What it does | Tests |
| --- | --- | --- |
| The window | One Slint file with the list's window and the question before a delete, with the properties the plugin sets and the callbacks it hears; OxiGuitar compiles and shows it. | `ui::tests::the_file_has_both_views_with_what_the_plugin_sets_and_hears`, `ui::tests::a_line_is_the_window_s_struct_and_an_index_is_a_whole_number`, `contract::the_plugin_file_keeps_the_contract` |
| Every copy listed | Every plugin file OxiGuitar found, a line a copy, a plugin's copies together, with its name, version and path; a file whose manifest can't be read is listed by its name. | `manager::tests::a_plugin_s_copies_are_listed_together_and_system_ones_stay`, `files::tests::every_copy_is_an_entry_and_the_newest_version_is_known`, `manager::tests::added_copies_join_their_plugin_and_replace_one_at_their_path` |
| System copies stay | A copy in a system folder is greyed out and can't be deleted; one inside the macOS app can't either; one beside a portable copy can when its folder can be written. | `files::tests::system_copies_are_never_deleted_and_the_macos_app_s_neither`, `files::tests::a_folder_that_can_be_written_is_told_apart`, `manager::tests::a_plugin_s_copies_are_listed_together_and_system_ones_stay` |
| Reading plugin files | A plugin file is an archive: its manifest and its library are its first two members, read from its bytes without unpacking; a file of the format before OxiGuitar 0.23 says so. | `oxp::tests::a_plugin_file_s_manifest_and_library_are_its_first_two_members`, `oxp::tests::a_bare_library_is_the_old_format` |
| The network mark | A `!` before the name of a plugin whose file's library imports the system's network functions; this plugin is marked. | `network::tests::network_calls_are_told_by_name_and_library`, `network::tests::what_isnt_a_library_says_so`, `contract::the_plugin_file_is_read_as_the_list_reads_others` |
| The newest release | A GitHub homepage names its repository; the newest release that isn't a draft and has a zip for this system is taken, pre-releases included; GitHub's hourly limit says when it lifts. | `releases::tests::a_github_homepage_names_its_repository`, `releases::tests::the_newest_release_with_a_file_for_this_system_is_taken`, `releases::tests::the_target_is_one_of_the_releases_names`, `releases::tests::the_hourly_limit_says_when_it_lifts` |
| Updating | Offered only when the newest release is newer than every copy; the download is checked against the release's SHA256SUMS, the plugin's files are taken from the zip and installed under the packages' names, where the copy OxiGuitar uses is when that folder can be written, or else in the user's folder. | `manager::tests::an_update_goes_where_the_used_copy_is_when_it_can`, `manager::tests::an_update_is_offered_once_a_plugin_when_a_release_is_newer`, `install::tests::a_download_is_checked_against_the_release_s_sums`, `install::tests::a_zip_without_the_plugin_says_so`, `install::tests::a_release_s_file_is_installed_under_the_package_s_name` |
| Installing a file | Only an OxiGuitar plugin file is copied into the user's folder, where OxiGuitar then finds it. | `install::tests::only_a_plugin_file_is_installed`, `contract::a_plugin_file_installed_in_the_user_s_folder_is_found_there` |
| Safe writes | A file replaces another whole, through a temporary name; what an interrupted write or a loaded copy on Windows left is cleaned up. | `install::tests::a_file_replaces_another_whole_and_leaves_nothing_behind` |
| A working plugin file | The `.oxp` file keeps the plugin contract, with this repository's SDK version and with the newest release of OxiGuitar. | `contract::the_plugin_file_keeps_the_contract`, `oxiguitar_plugin_checks::the_manifest_matches_the_plugin`, `stage:contract (latest core)` |
